# Smart Key-Remapping

Camera and F-key remapping with additional chat features to allow a more seamless transition between typing in chat and using your remapped keys.

---

## Features & Settings

* <span style="color: #ff9800;">**Click to Type:**</span> Allows you to click the chat input box to begin typing (disables hover highlight when disabled).
* <span style="color: #ff9800;">**Keep Typed Message On Click:**</span> Preserves your typed message when you click somewhere outside the chatbox.
* <span style="color: #ff9800;">**Stay Typing After Sending:**</span> Keeps you in a typing state after sending a message.
* <span style="color: #ff9800;">**Show Status When Not Typing:**</span> Displays a status indicator when not typing (Default: `Currently not typing...`).
* <span style="color: #ff9800;">**Typed Message Peek Key:**</span> Bind this to a key of your choice to temporarily hide the status indicator and view your typed message (most useful with *Keep Typed Message On Click* enabled).
* <span style="color: #ff9800;">**Appearance:**</span> Customize the status message text, status message color, and the highlight color when hovering over the chat input box.
